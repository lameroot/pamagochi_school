# Памагочи

Эта папка — самодостаточный статический сайт. Откройте `index.html`: все 28 заданий доступны в едином интерфейсе из семи уроков. `lab.html` оставлен как совместимая ссылка на лабораторию.

Сборка и backend не нужны. Для GitHub Pages достаточно опубликовать эту папку либо корень репозитория. Архитектура, добавление новых уроков и тесты описаны в `../README.md`.
